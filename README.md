# 🖥️ Arquitetura e Organização de Computadores I

Este repositório reúne as implementações desenvolvidas durante a disciplina de **Arquitetura e Organização de Computadores I** do **CEFET-MG – Campus Divinópolis**. Seu objetivo é organizar os exemplos e projetos produzidos pelo grupo, servindo como material de estudo, consulta e apoio ao aprendizado dos conceitos abordados em sala de aula.

---

## 🎯 Objetivo

Reunir em um único repositório as implementações dos principais componentes digitais estudados na disciplina, facilitando a organização dos projetos, o acompanhamento da evolução das atividades e a revisão dos conteúdos.

---

## 📁 Conteúdo

| Projeto | Descrição |
|---------|-----------|
| **Full Adder** | Implementação de um somador completo (Full Adder). |
| **Decoder** | Implementação de um decodificador. |
| **ULA 1 bit** | Unidade Lógica e Aritmética de 1 bit. |
| **ULA 8 bits** | Unidade Lógica e Aritmética de 8 bits. |
| **ULA 32 bits** | Unidade Lógica e Aritmética de 32 bits. |

---

## 🗂️ Organização

Cada projeto está organizado em sua própria pasta, contendo os arquivos necessários para sua implementação, facilitando a navegação e o estudo de cada componente individualmente.

```
📦 arquitetura-organizacao-computadores-1
├── 📁 FullAdder
├── 📁 Decoder
├── 📁 ULA-1bit
├── 📁 ULA-8bits
└── 📁 ULA-32bits
```
